# Baseball Growth Ver.3.8

Ver.3.8のCSV一括取込に加えて、同日・同一対戦相手を自動的に重複扱いしない安全な重複チェックを追加しました。

- 同日同カードの複数試合に対応
- 打順・守備・打数・安打・打点・盗塁・打席内容を比較して重複候補を判定
- 重複候補は自動削除せず、確認して片方だけ削除可能
- 任意で「第1試合／第2試合／第3試合」を記録可能
- localStorageキーは従来どおり baseballGrowthMultiV2 のため既存データを引き継ぎます
