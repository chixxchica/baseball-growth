# Baseball Growth Ver.4.0

今までの見やすさを維持しつつ、長く使うための土台を整理した完成版です。

- Firebase Authentication / Firestore同期
- 既存ローカルデータを保持
- 打席開始時の走者入力 → 得点圏を自動判定
- 試合区分：練習試合 / 公式戦 / 紅白戦 / その他
- 公式戦だけ大会名・何回戦を表示（任意）
- その他だけ試合名を表示（任意）
- 対戦相手・大会名・何回戦・試合名は過去入力から候補表示
- 同日カード（第1・第2・第3試合）対応
- 試合スコアは任意入力、勝敗を自動判定
- 過去の「大会」区分データは削除せず互換性を維持
- 打球方向、守備変更、CSV取込、重複チェック、成長グラフ等の既存機能を維持
