# Baseball Growth Ver.4.1

「記録する」だけでなく、成績・分析・成長を見返しやすくしたアップデートです。

- 成績／分析に共通フィルターを追加
  - 通算 / 今季 / 直近5試合 / 直近10試合
  - 学年
  - 試合区分
  - 大会・試合名
- フィルター対象の試合数を表示
- 分析（打順別・ヒートマップ・打球方向・打球タイプ・三振率・四球率・得点圏打率）も同じ条件で切替
- 成長グラフに「得点圏打率」を追加
- 学年別を「野球歴・学年別」カードに整理
- 選手管理 / CSV取込 / 重複チェック / バックアップを「データ・選手管理」に折りたたみ
- Ver.4.0.2までのFirebase同期、既存データ、過去成績の得点圏入力を維持

入力項目は増えていません。

Ver.4.2: 保存済み試合に投手記録（球数、投球回、被安打、奪三振、与四死球、失点、自責点、勝敗）を追加。投手集計と登板履歴。既存のデータ形式は維持。

Ver.4.3: 詳細打席に任意の投球経過入力（通常5種類＋ファウルチップ・バント）、編集による後日追記、カウント別分析を追加。既存のデータ形式とFirebase同期は維持。

Ver.4.3.1: 修正：投球入力ボタン初期化の順序によるログイン画面停止を修正。
